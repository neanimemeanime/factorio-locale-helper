# Factorio Mod Localization Helper & MCP Server

Инструмент и MCP-сервер для автоматизации анализа, перевода и аудита качества файлов локализации (`.cfg`) модов Factorio 2.1+ (включая Space Age).

---

## Возможности

1. **Пакетное сканирование недостающих строк (`scan_missing_keys` / `npm run scan`)**:
   - Читает `%APPDATA%\Factorio\mods\mod-list.json` и отбирает активные моды.
   - Извлекает оригинальные английские файлы (`locale/en/*.cfg`) на лету из папок и `.zip`-архивов.
   - Находит отсутствующие ключи по сравнению с базой `my-texture-pack/locale/ru/*.cfg`.
   - Опционально сохраняет заготовки `.cfg` в указанную папку.

2. **Аудит качества локализации (`audit_locale_quality` / `npm run audit`)**:
   - Ищет смесь языков (латиница рядом с кириллицей, например *"wooden бочка"*) и забытый английский текст.
   - Полная фильтрация служебных тегов Factorio (`[item=...]`, `[planet=...]`, `[color=...]`), плейсхолдеров (`__1__`), переменных Lua и технических терминов.

3. **Анализ отдельного мода (`analyze_mod` / `npm run cli`)**:
   - Статический анализ скриптов `.lua` и прототипов мода, обнаружение захардкоженных строк, фильтрация ванили и генерация чистого `.cfg`.

4. **Менеджер ванильных дубликатов (`manage_duplicates` / `npm run duplicates`)**:
   - Сверка с официальными данными Steam Factorio 2.1+ и безопасное комментирование (`#`) дублирующихся строк.

5. **MCP-сервер для ИИ (`npm run mcp`)**:
   - Поддержка протокола JSON-RPC 2.0 через stdio для интеграции с Claude, Gemini, Antigravity и Cursor.

---

## Быстрый старт

### Требования
- Node.js 20+
- Python 3.10+ (для модуля дубликатов)

### Команды
```bash
# Пакетный поиск недостающих строк:
npm run scan

# Аудит качества переводов:
npm run audit

# Запуск в режиме MCP:
npm run mcp

# Запуск локального HTTP API сервера (порт 3001):
npm run server
```

Подробная документация для ИИ-агентов находится в файле [AI_GUIDE.md](AI_GUIDE.md).
